# 提示词设计

组合顺序为基础工业设计约束、原图角色、主方向、辅助方向、重构幅度、参考图角色、用户需求、保留约束和输出要求。迭代图优先作为形态基础，原图用于功能校对。模板修订和实际发送的文本随版本保存。

结构化优化保留原始需求、硬性约束及不确定项，允许用户编辑或恢复输入。明确保留项优先，模板及需求中的潜在冲突在生成前提示。制造分析关注可见部件、分件、材料、装配维护与工艺边界。

L1–L5 表达从微调到概念探索的约束强度。材料建议要求列出厚度、牌号、替代材料、用量、风险和假设。成本由后端依据填写的参数计算。

## 模板维护

十个默认方向包含造型、外观、CMF、科技感、极简、高端、系列化、参考融合、成本和结构。各方向采用区别明确的形态及工程关注点。管理员可添加方向，调整顺序、说明、正文和启用状态。L1–L5 档位提供专有模板，修改将生成新的修订。每次生成的快照包含方向、档位修订和基础提示词版本。

## 校验与优先级

优先采用明确保留项，然后应用最终需求、重构档位及风格模板。优化只重组用户提供的约束和意图，遇到歧义提出待确认事项。预览给出常见保留与移除冲突、方向与档位交叉和缺少参考图等提示。外部模型的文本结果在进入界面前按任务的 JSON 字段校验。

Mock 对输入图执行可重复的本地配色与尺寸变化，文本和材料使用标记过的示例。输出用于核对图片角色、任务状态、追溯与存储流程。
