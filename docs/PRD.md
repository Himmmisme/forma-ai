# Forma AI V1.0 产品需求

Forma AI 供工业设计师、硬件研发和产品经理在局域网内协作使用。每个账号拥有独立数据空间，项目内汇总素材、设计版本、材料和成本方案。

| 领域 | 交付范围 |
| --- | --- |
| 身份 | 初始化超管、邀请式账号创建、启停、修改和重置密码、退出、普通用户与两级管理权限 |
| 项目 | 封面、名称及描述、搜索、收藏、归档、回收站和恢复、完整 ZIP 导出 |
| 设计 | 多张原图和参考图、拖放和粘贴、主辅方向、L1–L5 重构强度、保留项、提示词优化和预览 |
| 生成 | 依据模型能力选择参数、持久化生成任务、明确状态与失败原因、重试、原图和成果下载 |
| 版本 | 一张成果对应一个独立版本、父版本分叉、版本履历、任意设计图或原图并排比较 |
| 材料 | 依据二维成果识别可见部件，形成可编辑的概念级选型，并保存多份方案 |
| 成本 | 管理价格库，支持 Excel 导入导出，保存多份 BOM 及估算，记录价格来源及计算假设 |
| 配置 | 独立的服务商、模型和默认模型管理，测试连接及能力，模板维护，审计和备份 |

新部署适用内置 Mock。真实服务商只在超管完成配置后使用。发往外部服务的输入含所选素材与用户需求，应用在提交入口明确告知。

材料与成本输出用于方案评审。内部结构、尺寸、重量、材质牌号和供应商报价由用户按实际数据确认。成本使用人民币，明示税费与电子器件范围。

## 业务约束

- 超管管理初始账号、外部 API、系统设置和备份。管理员维护普通用户、提示词模板和价格库。普通用户通过界面和 API 访问本人项目与衍生记录。项目归档后可查看，取消归档后可投递新的设计任务。
- 进入回收站的项目从常规视图隐藏，恢复后可继续访问。项目导出包含过去和现在的素材、版本、原始建模参数、实际提示词、调用记录及相关分析方案。
- 产品原图可上传多角度，参考图用于外观和 CMF 约束，当前迭代图用于继承父版本的设计。界面支持预览、选择、拖放、粘贴和移除。上传单张上限 12 MB，解码后最多 2400 万像素，支持静态 PNG、JPEG、WebP。上传图按方向校正、移除元数据并以长边至多 2800 像素的 WebP 保存。生成成果保留上游返回的原始字节。
- 主方向必选，辅助方向最多 5 项。重构档位表达设计约束。优化结果可采用、编辑、重新优化或恢复原始需求。遇到潜在冲突时展示提示并由用户确认。
- 生成任务显示真实状态，失败保留原因和请求记录。一次任务的每张成果都有独立版本编号。可从历史分支继续改图、收藏、下载和与原图比对。
- 方案可保存多个版本，每条成本计算可追溯到用户报价、材料库报价或明确标记的 AI 参考估价。成本 UI 支持缺项、税费、损耗、多部件及模具分摊。
