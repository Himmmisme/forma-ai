# 数据库设计

| 实体 | 用途 |
| --- | --- |
| 用户与会话 | 密码哈希、角色、状态、随机会话令牌摘要及有效期 |
| 项目与素材 | 用户所有权、项目状态、封面、素材种类和服务端文件标识 |
| 模板 | 方向、重构强度、启用状态、排序及修订 |
| 服务商与模型 | 加密凭据、连接配置、能力、输出规格、计费说明及任务绑定 |
| 任务与调用 | 队列状态、幂等键、租约、上游用量和状态 |
| 设计版本 | 项目内编号、父版本、完整输入及参数快照、独立成果 |
| 材料价格与方案 | 供应商价格库、部件选型方案、成本输入与计算快照 |
| 系统设置和审计 | 初始化与运行设置、管理事件 |

项目数据由项目所有者访问。版本保存素材 ID 及模板和模型快照。删除素材后从活动列表隐藏，历史版本可继续读取其记录。

- 标识符为 32 字符随机 UUID，时间以 UTC 保存并转换为浏览器本地时间。素材路径按标识符生成，内容类型、尺寸、大小与 SHA-256 记录于 `assets`。
- `users` 持有 `projects`，项目拥有 `assets`、`design_versions` 和 `jobs`。用户与项目的所有权在服务端查询同时匹配，管理账号的系统权限与项目所有权分别校验。
- `design_versions` 对项目内编号加唯一约束，使用 `parent_id` 连接上一版本。一次生成多张图时按请求数量预留编号，每张图写入独立版本和独立素材。任务快照保存原始、优化、最终需求及模型配置。
- `jobs` 对用户、任务种类及幂等键加唯一约束，保存请求指纹与当前尝试编号。`call_logs` 追加记录每次请求的 HTTP 状态、耗时、可获得的用量和请求 ID。
- `material_plans` 与 `cost_plans` 都连接到设计版本。价格库使用材料、牌号、规格、工艺、供应商作为复合标识。成本快照保存精确小数输入和实际使用的报价。
- Alembic `0001` 建立表与索引，`0002` 建立用于串行化首次初始化的记录。应用首次启动写入内置模板和 Mock 模型。
