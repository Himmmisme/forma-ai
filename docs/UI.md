# 交互规范

工作区使用深色左导航和低饱和中性色画布，突出图片及当前操作。界面以中文为主，提供浅色和深色主题及清晰的键盘焦点。概览可进入最近项目、创建项目或载入演示素材。

工作台左侧依次组织输入图片、设计方向、重构强度、用户需求及输出设置。右侧展示任务和生成成果，下方展示历史版本。成果动作包含图片放大、迭代、比较、参数、材料、成本、收藏及下载。

管理后台按功能分区，并依据角色显示对应操作。队列使用排队、生成中、成功和失败等真实状态。材料、成本和 Mock 结果使用就近说明。

导航提供概览、项目、设计、版本、对比、材料成本、素材和收藏入口。登录、个人设置、用户管理、API、模板、报价和系统备份共用表单、结果状态、弹窗和操作样式。工作台右侧成果保留在桌面视口内，移动宽度时两列叠放。对比视图保留各侧独立的图片选择和放大操作。

上传框可通过文件选择、拖拽及聚焦后粘贴使用。预览、版本参数和方案编辑使用原生对话框，支持 Esc 关闭。深浅色选择保留在当前浏览器。主要图片和示例图为原创工业设计素材。
